# 🚀 PrepWise AI — Technical Interview Simulator

**PrepWise AI** is an AI-powered interview simulation platform that evaluates candidates the way a **senior engineer or architect would** — not just by asking questions, but by analyzing depth, clarity, and real-world thinking.

It bridges the gap between **preparation and actual interview expectations** through resume-aware questioning and diagnostic feedback.

---

## 💡 Core Value Proposition

> **“Resume-aware intelligence with actionable performance insights.”**

* Generates **personalized interview questions** from candidate resumes
* Evaluates **technical depth, communication, and problem-solving**
* Provides **structured, recruiter-friendly feedback**

---

## 🛠️ Tech Stack

### Frontend

* **React.js + Tailwind CSS** → Fast, responsive UI
* **Recharts** → Radar chart for performance visualization

### Backend

* **Node.js + Express** → API & workflow orchestration
* **Groq SDK (Llama 3.3–70B)** → High-speed AI inference
* **MongoDB** → Data storage (profiles, sessions)
* **Multer + pdf-parse** → Resume upload & parsing

---

## 🌟 Key Features

### 1. Resume-Aware Question Generation

* Extracts skills, experience, and projects from resume
* Generates **relevant, role-based technical questions**

### 2. AI-Based Evaluation Engine

* Analyzes candidate answers
* Scores across:

  * Technical Knowledge
  * Communication
  * Confidence

### 3. Diagnostic Feedback System

* **Ideal Answers** → Benchmark responses
* **Gap Analysis** → What candidate missed
* **Action Plan** → Targeted improvement steps

### 4. Performance Visualization

* Radar chart for multi-dimensional evaluation
* Clear breakdown for quick understanding

## ⚙️ How It Works

1. Upload Resume → Parsed into structured profile
2. Generate Questions → Based on skills & projects
3. Submit Answers → User responses collected
4. AI Evaluation → Scores + feedback generated
5. Results Dashboard → Visual + textual insights
